# Security policy

## Reporting a vulnerability

If you find a way to make `verify_payment` accept a payment it shouldn't, make `claim_payment` succeed twice, or get `decrypt_notification` to accept a forged notification, report it privately:

- Use [GitHub private vulnerability reporting](https://github.com/xeroxzen/oppwa-guard/security/advisories/new), or
- Email andilembele020@gmail.com with the subject `oppwa-guard security`.

Include the version, a minimal reproduction, and the impact you expect. You'll get an acknowledgement within 3 working days.

Please don't test against a live merchant or gateway you aren't authorised to test.

## Supported versions

Only the latest release receives fixes.
